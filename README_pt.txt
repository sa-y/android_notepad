Bloco de notas simples
======================

O Bloco de notas simples é uma aplicação de bloco de notas simples para Android.

As seguintes funções são suportadas.
 * Adicionar nova nota a partir de um modelo
 * Pesquisar nota
 * Criar o atalho para uma nota

Este software tem as seguintes características.
 * Operação com teclado físico
 * Sem publicidade
 * Código aberto
