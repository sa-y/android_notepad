Bloc de notas simple
====================

Bloc de notas simple es una aplicación de bloc de notas sencilla para Android.

Se admiten las siguientes funciones.
 * Añadir nueva nota desde una plantilla
 * Buscar nota
 * Crear el acceso directo a una nota

Este software tiene las siguientes características.
 * Funcionamiento con teclado físico
 * Sin publicidad
 * Fuente abierta
